# 同层卡：统一预览与审核

适用当前 MMD 旧页（`chatVersion:0` / 缺省）的 [同层卡基座](../../assets/same-layer-kit/README.md)。同一个入口固定作品源码，构建导入文件，执行审核，并生成可切换的 MMD / 同层卡联动预览。

## 一个入口如何工作

```text
作品配置 + 同层卡源码
  → 固定本次源码副本
  → 发布正则包 + Frame + 发布清单
  → 通用格式审核 + 载荷/脚本审核
  → 旧 MMD 模拟页面 + 原样发布载荷
  → 浏览器交互检查 + 截图 + 统一报告
```

预览使用 `build-preview.py` 已有的旧 MMD 全景页面结构、主题变量和尺寸规则，动态动作由原创本地模拟器提供。原生页与同层页共享一份消息、模型、会话、人设及设置状态。模拟器定义明确的本地游戏存档作用域，切换会话时由正式 Host 重建 Frame 并切换存档。

被测的 Host、Frame、分片包装和启动器来自本次发布文件，保持原样；使用正式原生 DOM 桥接，不把载荷换成 Mock。原生页是同源 HTTP 文档，卡片 Frame 仍为隔离的 iframe，通过原有握手与 MessagePort 通信。不能为了预览放宽来源检查或让 Frame 读取父页 DOM。

对作者是一个预览地址，顶部切换 **MMD 页面 / 同层页面 / 审核报告**；内部保留原生宿主文档和独立 Frame，与部署架构对应。它不接管真实 MMD 账号或服务器。

## 原生页面保留范围

原生页保留已有旧 MMD 全景预览的 **6 个快捷入口、11 个更多入口和 7 种面板模板**。模板从 `build-preview.py` 作为非活动模板载入，打开时克隆，再接本地共享状态；原来的静态脚手架不同时执行。

- 快捷入口包括模型设置、对话设置、选择指令、总结剧情、新的聊天、用户人设。**模型设置直达当前模型参数**，模型名称入口才打开模型列表；快捷“新的聊天”先确认新建，更多菜单“新的聊天”打开会话记录。
- 恢复总结保存、聊天导出、角色编辑、用户消息编辑/分享。模型参数使用 2026-09-16 旧页实机核对后的共享模板：输出 Token 上限、右侧提示、流式输出、每次消耗信息栏和底部确认；不添加适配器测试里的篇幅、预设或记忆演示项。人设、补充设定、指令与会话仍共用状态。
- 背景支持本地颜色和图片选择；评论、帮聊及重置提供明确标注的本地行为。编辑角色不会修改发布卡，导出不会包含账号凭据。
- 同层页只调用已审核的 61 项桥接动作。导出、角色编辑、总结等原生页面入口的恢复**不自动新增同层动作接口**；仅定义的动作继续保持不可用。需要这些功能时返回原生页使用。
- 检测到原生弹窗时，Host 暂时隐藏“返回游戏”浮钮，关闭弹窗后恢复，避免遮挡原生关闭控件。

模型参数还需对照 `scripts/fixtures/mmd-legacy/model-observed.json` 的实机采样标签、选项、分组和关键样式；仅有按钮可点击不足以认定原生一致。模型名和电量是本地演示数据，不能作为平台目录或价格。

完整性检查从旧预览源码提取入口清单，比较恢复页实际入口，并逐项检查打开、保存/重开、导出、取消/确认和窄屏。清单写在 `preview-manifest.json` 的 `nativeInventory`。原生检查与同层 UI 模块开关独立，避免关闭某个卡片模块时跳过原生页面检查。

## 制作与运行

1. 复制完整 `assets/same-layer-kit/` 到项目源码目录，按 [对话页模块](same-layer-dialogue.md) 制作界面和功能。
2. 将随资产提供的 `same-layer.project.example.json` 复制为作品配置，例如 `same-layer.project.json`，修改作品名、`appId`、`buildId`。`source` 相对配置文件所在目录解析；源码与配置同目录时保留 `"."`。每次候选使用明确的版本标识和新输出目录。
3. 从**实际 skill 根目录**调用以下入口，路径按所在环境填写，不假定某个客户端的安装位置：

```sh
python scripts/review_same_layer.py --project <作品配置.json> --out <新的审核目录> --browser required
python -m http.server 8765 --bind 127.0.0.1 --directory <审核目录>
```

打开 `http://127.0.0.1:8765/review-report.html`，从报告进入联动预览；也可直接访问 `/preview/preview.html`。需保留整个目录，不能只复制一个 HTML，也不要用 `file://` 代替本地 HTTP。

### 配置与运行环境

| 项目 | 说明 |
|---|---|
| `platform` / `chatVersion` | 固定 `"mmd"` / `0`。新页会被拒绝，应改用新页 SDK 流程 |
| `source` | 同层卡源码目录，相对作品配置文件解析 |
| `appId` / `buildId` / `title` | 作品稳定标识 / 本次发布版本 / 宿主标题；页面正文文案仍在 Frame 源码修改 |
| `engine` / `models` | 布尔值，默认均为 true；纯聊天卡可关闭 engine |
| `allowedActions` | 可选动作白名单，采用 [已有动作名](../runtime/mmd-native-capabilities.md)；省略沿用基座默认，空数组停用所有原生动作。UI 开关不会扩大权限 |
| `preview.messages` | 可选初始消息，每项仅 `role`（user/assistant）与 `text`；仅改变本地演示数据，不写入发布卡 |
| Node | 同层载荷脚本语法审核必需；从 PATH 查找，也可传 `--node <路径>` |
| Playwright | 使用环境中已安装的库，`PLAYWRIGHT_MODULE` 指向其模块入口；工具不会自行下载依赖或浏览器 |
| 浏览器 | Windows 默认 Edge；可通过 `BROWSER_CHANNEL` 选择已安装的浏览器通道 |

`--browser required` 缺环境或交互失败均返回 FAIL。默认 `auto` 缺浏览器环境则 PARTIAL；`skip` 也为 PARTIAL，明确记录未跑浏览器。命令退出码：0 本地自动项通过，1 失败，2 未完成。已经存在的输出目录不会覆盖。

## 审核产物与证据

| 产物 | 用途 |
|---|---|
| `source/`、`review-inputs.json` | 此次构建源码副本、配置与 SHA-256 |
| `release/same-layer-mmd.json` | 可交付的旧页四字段正则包；整卡另封装 v2 PNG |
| `release/frame.html`、`release-manifest.json` | 对应 Frame 与发布清单；Frame 单独打开不能验证宿主功能 |
| `preview/` | 联动预览及模拟资源；预览清单记录对应的发布载荷/Frame 哈希 |
| `validation.txt` | 通用校验结果及需要阅读的提示 |
| `browser/results.json`、截图 | 实际浏览器检查结果、桌面与 390px 窄屏截图；失败时尽力保存诊断 |
| `review-report.html/.md/.json` | 人工阅读和自动处理的同一份报告 |

默认浏览器脚本验证**本基座对话 UI 的结构合同**：原样载荷连接和 Frame 隔离、双输入框同步、双向发送、模型/人设同步、补充设定保留、原生草稿保护、会话切换与游戏进度隔离、离开/返回和窄屏。被作品权限或模块开关关闭的流程标为不适用；详细结果逐项记录。此外独立运行 `review_same_layer_native.mjs` 验证原生页面保留范围。它们不是平台全功能认证，也不逐次重跑基座全部 61 项动作回归。

更换整个 Frame 结构或引擎语义时，应同步适配 `review_same_layer_browser.mjs` 中相应的定位和行为断言；不能把默认脚本的失败直接当作平台不支持，也不能删除必要断言后声称已覆盖原流程。外观、文案和剧情质量仍需查看预览与截图；自动报告中的人工视觉审核默认 `NOT RUN`，实际检查另记到项目审核记录。

构建或载荷校验失败时保留失败报告，不生成可用预览。浏览器失败时保留候选、截图及日志供修复；改源码后运行新目录，不能用旧的通过报告证明新代码。

## 模拟精度

消息编辑已按实机补齐气泡圆钮、全屏编辑遮罩、离线 Vditor、文字工具和保存按钮的稳定选择器；具体结构、动态 ID、样式和未验证范围见 [消息编辑实机记录](../runtime/mmd-message-editor.md)。统一审核同时检查原生编辑窗口与同层编辑联动。未核实规则的两项异常清理保留入口但禁用。

| 层面 | 本地能证明什么 | 尚需真实环境验证 |
|---|---|---|
| MMD 页面 | 复用已有观察记录中的层级、深色变量、rem 缩放及双输入框结构 | 前端新版本、真实 Markdown/净化与 CSP |
| 原生动作 | 正式桥接对模拟 DOM 的定位、参数、确认和共享状态流转 | 实际账号权限、生成时序、服务端结果 |
| 模型与设置 | 本地选择和表单状态，两页同步 | 真正的模型列表、计费、生成和平台保存 |
| 游戏 | 确定规则、当前浏览器存档和本地会话隔离 | 真实账号/角色/会话解析器、跨设备手动转存 |
| 外观与输入 | 桌面/窄屏可操作与截图 | 实体手机、软键盘和触控差异 |

原有面板外壳被保留，其中部分选项、图标、回复和教程等仍为本地模拟；输入区多行判定简化，不复刻裸赋值轮询时序。不能称为完整 MMD 复刻，也不能把本地桥接成功当成真实后端连接成功。

原有 `build_same_layer.py --preview` 保留作聊天/模型/游戏 Mock；`preview_same_layer_dialogue.py` 保留作动作/UI 夹具诊断。正常同层作品验收优先走本统一入口。普通气泡美化、新页 SDK 预览继续各自原有流程；通用 `validate.py` 被复用，专项审核保持单独模块维护。

模型实机证据范围：本轮已手动核对一个 GLM 参数面板并恢复 5000 / 流式开启；这不代表全部模型目录、服务端生成或同层桥接已在真实平台验收。示例参数按模型保存在本地，正式 Frame 仍读取原生当时提供的控件。
